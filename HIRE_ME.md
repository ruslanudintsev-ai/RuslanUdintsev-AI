## What I can help deliver

I organize **small, bounded AI-assisted software workflows** from a real problem to a reviewable result:

1. Translate an idea into requirements, constraints, acceptance criteria and a realistic work plan.
2. Split independent work between AI coding agents (for example, data/import and UI), keeping branches and permissions separated.
3. Coordinate GitHub issues, pull requests and CI evidence; detect failed checks and unclear handoffs.
4. Conduct practical acceptance checks; distinguish *implemented*, *tested*, *merged*, *deployed* and *measured impact*.
5. Deliver a concise handoff: what changed, what was verified, remaining risks and recommended next action.

**My role is coordination, product decisions and QA.** Significant implementation is written with Codex, Gemini and other coding agents. I do **not** represent that output as independently hand-coded by me.
