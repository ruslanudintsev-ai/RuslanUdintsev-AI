# 🤖 Демонстрационный Telegram Бот

Интерактивный бот для демонстрации возможностей библиотеки `python-telegram-bot`.

## 📋 Возможности

- **Команды:**
  - `/start` - Приветственное сообщение с интерактивными кнопками
  - `/help` - Справка по всем командам
  - `/echo <текст>` - Повторяет ваш текст
  - `/info` - Показывает информацию о пользователе и чате

- **Интерактивные элементы:**
  - Инлайн-кнопки в главном меню
  - Многоступенчатые диалоги
  - Обработка нажатий на кнопки

- **Обработка сообщений:**
  - Ответы на обычные текстовые сообщения
  - Логирование ошибок

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

### 3. Настройка токена

Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте ваш токен:

```
TELEGRAM_BOT_TOKEN=ваш_токен_бота_здесь
```

### 4. Запуск бота

```bash
python bot.py
```

## 🎮 Примеры использования

После запуска бота:

1. Отправьте `/start` - увидите приветственное сообщение с кнопками
2. Нажмите на кнопки для навигации
3. Используйте `/help` для просмотра всех команд
4. Попробуйте `/echo привет` - бот повторит ваш текст
5. Отправьте `/info` - получите информацию о себе

## ⚙️ Технологии

- **Python 3.7+**
- **python-telegram-bot v21.0** - асинхронная библиотека для Telegram Bot API
- **python-dotenv** - управление переменными окружения
