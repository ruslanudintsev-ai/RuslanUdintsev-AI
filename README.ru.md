## Как я работаю

```mermaid
flowchart LR
    G["Цель"] --> T["ТЗ и критерии"]
    T --> A["ИИ-агенты"]
    A --> C["PR и CI"]
    C --> Q{"Проверено?"}
    Q -->|Нет| T
    Q -->|Да| R["Решение о релизе"]
```

У каждого исполнителя — собственная зона ответственности. Ошибки не прячем; запрос к агенту, рабочая ветка, зелёные тесты, слияние и production — **разные состояния**.
