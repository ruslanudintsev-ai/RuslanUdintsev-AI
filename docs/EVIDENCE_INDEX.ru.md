## Независимый контроль качества ИИ-агентов

[Отдельная практика со схемой, примером и чек-листом](INDEPENDENT_AGENT_REVIEW.ru.md): чат-исполнитель → второй чат-ревьюер → замечания в GitHub на конкретном SHA → исправления → повторная проверка → решение владельца. Пример основан на закрытом документационном проекте; публичная проверяемость его исходников **не заявляется**. Приближённая схема Graphviz **не считается** пройденным визуальным QA GitHub Mermaid.

## Исполняемый демонстрационный инструмент

**[Самостоятельная проверка за 5 минут — команды, ожидаемые результаты и эксперимент с нарушением границ](TRY_IT.ru.md).**

[Локальная проверка PR и CI на Python](../examples/pr-evidence-gate/README.md) — небольшая демонстрация на стандартной библиотеке с синтетическими входными данными и 13 тестами. Проверяет границы изменений, статусы CI и уведомления от самого агента. **Выпуск всегда требует решения человека.** Это AI-assisted прототип, не подключённый к живому GitHub, и не доказательство самостоятельной production Python-разработки.

## Что покажу в небольшом практическом задании

1. **Вход:** ограниченная задача в GitHub и согласованные критерии готовности.
2. **План:** зоны ответственности агентов, ограничения, границы PR и сценарии ошибок.
3. **Выполнение:** согласованная AI-assisted реализация или read-only проверка PR/CI при наличии разрешённого доступа.
4. **Передача:** проверяемый отчёт с SHA, CI/тестами, рисками, неизвестным и рекомендацией по выпуску.

Доступ к production и секретам не предполагается. Зелёный CI — не то же, что публикация; публикация — не то же, что индексация или доход.

## Какие навыки подтверждены

- **Личная практика:** ТЗ для ИИ-агентов, Issues/PR, координация разработки, приёмка и QA.

- **Продолжаю изучать:** самостоятельный Python backend, RAG и ML-инженерию.
